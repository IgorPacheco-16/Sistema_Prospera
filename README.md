Sistema OP - Gestão de Produção

Sistema web desenvolvido em Flask para gerenciamento de Ordens de Produção (OPs), com foco em organização, fluxo de tarefas e identificação de gargalos.

Funcionalidades:

-  Criação de Ordens de Produção
-  Definição de setores e tarefas
-  Controle de prazos
-  Dashboard com indicadores
-  Sistema de notificações automáticas
-  Calendário de tarefas
-  Controle de status (aberta, em andamento, finalizada)
-  Sistema de usuários por setor

Tecnologias:

- Python (Flask)
- SQLite
- HTML + CSS (Bootstrap)
